# Dipali Parabiya — Motion Narrative Portfolio

A cinematic personal portfolio built around the theme **“Motion Narrative — My Story in Motion.”**

## Stack
- HTML5
- CSS3
- Bootstrap 5 (responsive utility layer)
- JavaScript
- jQuery
- Bootstrap Icons
- Canvas particle system (no Three.js/WebGL dependency)

## Run
Open `index.html` in a browser, or serve the folder with any simple local web server.

The resume PDF is included at:
`assets/Dipali_Parabiya.pdf`

## Content source
Portfolio content is based on the uploaded resume. No external portfolio facts were added.
